# Third-Party Notices & Media Provenance (`docs/`)

This interactive web showcase (`docs/`) presents the **Fantasy Basketball** graduation project as an unmonetized, static software-engineering portfolio demonstration. It is not affiliated with, endorsed by, or sponsored by the NBA, Euroleague Basketball, any basketball club, or any athlete.

## 1. Original Graphics Authored for This Showcase
The following vector graphics in `docs/assets/` are original works created specifically for this static showcase (containing no third-party trademarks or artwork):
- `docs/assets/basketball-logo.svg` — Original basketball emblem matching the visual style of `ContentView.swift` / `HomeView.swift`.
- `docs/assets/teams/gsw.svg`, `docs/assets/teams/lal.svg`, `docs/assets/teams/phx.svg`, `docs/assets/teams/fb.svg` — Original geometric monogram badges replacing trademarked franchise/club logos in `TeamsView`.
